외우는 말: "외-꼭, 내-변" · 실생활에서 세 점이면 외심, 세 선이면 내심

3점수가 깎이기 쉬운 곳

  • ✗ 내심이 세 꼭짓점에서 같은 거리라고 씀 → 세 변까지
  • ✗ 내접원 반지름을 IA로 잡음 → I에서 변에 내린 수선 ID
  • ✗ 수선의 발 D·E·F, 직각 표시를 빠뜨림
  • ✗ 접은 선을 일부만 그림 → 모두 자로 긋기
  • ✗ 둔각삼각형에서 접은 선을 연장하지 않아 O를 못 찾음
  • ✗ 서술형에 "외심이니까"만 씀 → 성질(같은 거리)을 근거로
  • ✗ 합동 설명에서 조건 이름(SAS, RHA)과 "공통" 생략
  • ✗ 직각삼각형의 외심을 안쪽에 찍음 → 빗변의 중점
  • ✗ 원을 그린 뒤 확인 안 함 → 외접원은 세 꼭짓점을 지나고, 내접원은 세 변에 닿아야 해요

4우리는 앞으로 이런 공부를 해야 해요

외심·내심은 이번 평가로 끝나는 내용이 아니에요. "같은 거리", "합동으로 이유 대기", "작도"는 앞으로 배울 도형 단원 모두에서 다시 나옵니다.

지금 · 삼각형의 성질이등변삼각형, 외심·내심, 합동으로 설명하기
다음 · 사각형의 성질평행사변형·마름모·직사각형 성질을 합동으로 증명
중2 · 닮음, 피타고라스닮음비, 직각삼각형 변의 길이 (외접원 반지름 계산에도 쓰임)
중3 · 원의 성질현의 수직이등분선, 접선, 원주각 (외접원·내접원의 확장)
① 말로 설명하기 공식만 외우지 말고 "뜻 → 성질 → 왜 그런지"를 친구나 선생님께 30초 안에 말해 보기.
② 손으로 그리기 눈으로 보는 공부는 금방 잊어요. 자·컴퍼스·색종이로 직접 그리고 접고, 표시까지 완성하기.
③ 서술형은 틀에 맞춰 "조건(근거) → 합동 조건 이름 → 결론" 순서로 쓰기. 근거 없는 결론은 점수가 없어요.
④ 오답은 이유로 정리 답만 고치지 말고 "어떤 개념을 헷갈렸는지" 한 줄로 쓰기. 같은 실수가 두 번 나오면 개념부터 다시.
⑤ 실생활 문제는 질문부터 "같은 거리인 게 점인가, 선인가?"를 먼저 묻는 습관. 문제를 수학 그림으로 바꾸는 연습.

5나의 점검

외심·내심의 뜻을 말할 수 있다 삼각형 모양별 외심 위치를 안다 OA=OB=OC를 합동으로 설명한다 종이접기로 O와 I를 찾을 수 있다 외접원·내접원을 바르게 그린다 이어폰·소방서 문제를 설명한다

정확히 알고, 직접 그리고, 이유를 말할 수 있으면 도형은 어렵지 않아요.
